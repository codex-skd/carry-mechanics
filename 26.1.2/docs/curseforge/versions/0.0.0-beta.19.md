<h2>v0.0.0-beta.19 - Block rendering in first and third person</h2>

<h3>Fix</h3>
<ul>
<li><strong>Third-person rendering</strong>: <code>CarryingItemRenderLayer</code> added as a <code>RenderLayer</code> to AvatarRenderer, showing the carried block on the player model.</li>
<li><strong>First-person rendering</strong>: Mixin into <code>AvatarRenderer.renderHand()</code> renders the carried block after the hand model.</li>
<li><strong>Carry data injection</strong>: <code>AvatarExtractorMixin</code> injects carry data into <code>AvatarRenderState</code> during extraction.</li>
</ul>

<h3>Requirements</h3>
<ul>
<li>Minecraft 26.1.2</li>
<li>NeoForge 26.1.2.78</li>
</ul>
