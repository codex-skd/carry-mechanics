<h2>v0.0.0-beta.35 — Position Fix &amp; Scaling</h2>

<h3>Changes</h3>
<ul>
<li><strong>Position:</strong> Moved block to the player's left shoulder area (<code>X=-0.3</code>) instead of right.</li>
<li><strong>Scale:</strong> Added 60% scale (<code>0.6f</code>) for a more natural carried-item size.</li>
<li><strong>Height:</strong> Slightly lowered from previous version to sit just above the head (<code>Y = -(boundingBoxHeight + 0.2)</code>).</li>
</ul>

<h3>Known Issues</h3>
<ul>
<li><strong>First-person:</strong> Block only visible in third person (F5). The player model is not rendered in first person by the AvatarRenderer, so the RenderLayer cannot display there. A separate first-person overlay will be added in a future release.</li>
</ul>
