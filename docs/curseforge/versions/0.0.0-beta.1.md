<h2>v0.0.0-beta.1 — Initial port to Minecraft 26.2</h2>

<p>First build of Carry Mechanics for Minecraft 26.2 (NeoForge 26.2.0.41-beta), ported from the stable 26.1.2 release (<code>1.0.0</code>). Same feature set: carrying blocks, entities and tile entities, entity stacking, whitelist/blacklist via datapack tags, scripting, commands and full multiplayer sync.</p>

<h3>Technical Changes</h3>
<ul>
<li><code>CarryData.getEntity()</code> — <code>EntityType.create(input, level, EntitySpawnReason.BUCKET)</code> replaced with <code>EntityType.create(input, level, new EntitySpawnRequest(EntitySpawnReason.BUCKET, false))</code>. The static <code>create(ValueInput, Level, EntitySpawnReason)</code> overload was removed in NeoForge 26.2 in favor of <code>create(ValueInput, Level, EntitySpawnRequest)</code>. This was the only code change required for the port.</li>
</ul>

<p>NeoForge 26.2.0.41-beta is still a beta build; treat this release as early-access for MC 26.2.</p>
