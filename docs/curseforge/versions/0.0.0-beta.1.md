<h2>v0.0.0-beta.1 — Initial Fabric port</h2>

<p>First <strong>Fabric</strong> build of Carry Mechanics for Minecraft 26.2 (Fabric Loader 0.19.3 / Fabric API 0.156.0), ported from the NeoForge 26.2 codebase.</p>

<h3>Features</h3>
<ul>
<li>Pick up, carry and place blocks (with their tile entities) and entities using your bare hands.</li>
<li>Entity stacking, whitelist/blacklist via datapack tags, datapack scripting, commands and 25+ config options.</li>
<li>Config file: <code>config/carry_mechanics.json</code>.</li>
</ul>

<h3>Notes</h3>
<ul>
<li>Porting notes: NeoForge attachments were replaced by a UUID-keyed <code>CarryData</code> store synced over a custom packet; <code>RenderHandEvent</code> was replaced by a mixin; the TOML config became JSON; events and networking were rewritten to Fabric API callbacks.</li>
<li>Includes the rendering fixes from NeoForge 1.0.2/1.0.3 (safe pose-stack rendering and carried-entity ID assignment), so carried mobs render correctly in first and third person.</li>
<li>Beta: mob rendering is still being polished. Block carrying works fully.</li>
</ul>
