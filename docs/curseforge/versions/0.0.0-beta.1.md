<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of Carry Mechanics for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). Same carry system as the 26.2 build.</p>

<h3>About this build</h3>
<ul>
<li><strong>Port from the 26.2 line</strong>: the 26.2 fork tree with every 26.2-only Minecraft/NeoForge API reverted to 1.21.1, using upstream <a href="https://www.curseforge.com/minecraft/mc-mods/carry-on">Carry On</a> 1.21.1 (v2.2.6, Tschipp / PurpliciousCow, LGPL-3.0) as the API reference. The fork's own gameplay dynamics are preserved.</li>
<li><strong>Feature set</strong>: sneak-to-pick-up blocks (with block entities) and entities, place anywhere, entity stacking, weight/slowness, datapack whitelist/blacklist tags, the JSON scripting engine, model overrides, and the <code>/carrymechanics</code> commands.</li>
<li><strong>Dependencies</strong>: none. GameStages is optional (for script conditions).</li>
</ul>

<h3>Notes</h3>
<blockquote>Install on both client and server. <strong>LGPL-3.0</strong> (fork of Carry On): the mod stays under the LGPL, keeps the original Carry On copyright, and its complete source is published in the repository. Verified: <code>./gradlew build</code> and <code>./gradlew runServer</code> load cleanly server-side; the client render code is compile-checked only.</blockquote>
