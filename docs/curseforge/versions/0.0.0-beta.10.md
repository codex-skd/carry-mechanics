## v0.0.0-beta.10

**fix:** Jump prevention was not working because the mixin targeted `LivingEntity` instead of `ServerPlayer` (which overrides the method).

### Changes
- Mixin moved from `LivingEntity.jumpFromGround()` to `ServerPlayer.jumpFromGround()`
- Players can no longer jump while carrying an object

### Requirements
- Minecraft 26.1.2
- NeoForge 26.1.2.78

### Known issues
- Carried object has no visual rendering (invisible)
