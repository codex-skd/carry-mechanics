## v0.0.0-beta.11

**feat:** First-person block rendering when carrying an object. Improved jump prevention.

### Changes
- Implemented block rendering in the right hand using `BlockModelRenderState` + `SubmitNodeCollector` API
- Jump prevention now uses direct Y-velocity cancellation in server tick (more reliable)
- Removed `ServerPlayer.jumpFromGround()` mixin (was not intercepting correctly)

### Requirements
- Minecraft 26.1.2
- NeoForge 26.1.2.78
