## v0.0.0-beta.12

**fix:** Jump prevention was not working. Replaced mixin with direct Y-velocity cancellation in server tick.

### Changes
- Removed `ServerPlayer.jumpFromGround()` mixin (did not intercept correctly in this version)
- Jump prevention now uses velocity cancellation in `ServerTickEvent.Post`
- Block rendering uses `submitMultiLayer()` for multi-layer block support
- Updated WORKFLOW.md with language guidelines

### Requirements
- Minecraft 26.1.2
- NeoForge 26.1.2.78
