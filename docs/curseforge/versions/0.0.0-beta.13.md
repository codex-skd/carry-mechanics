## v0.0.0-beta.13

**fix:** Carried block rendering now uses `ItemStackRenderState` instead of `BlockModelRenderState`.

### Changes
- Changed render approach to render the block as an `ItemStack` using `ItemModelResolver`
- Uses `ItemDisplayContext.FIRST_PERSON_RIGHT_HAND` for proper positioning
- Carried blocks should now be visible in first-person view

### Requirements
- Minecraft 26.1.2
- NeoForge 26.1.2.78
