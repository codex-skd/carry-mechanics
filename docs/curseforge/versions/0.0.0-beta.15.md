## v0.0.0-beta.15

**fix:** Carried block rendering now uses `ItemInHandRenderer.renderItem()` for first-person hand display.

### Changes
- Added mixin into `ItemInHandRenderer.renderItem()` which is the actual method that renders items in first-person hands
- When the player's hand is empty and they are carrying a block, the block's item is rendered instead
- Removed `AvatarRendererMixin` (it only renders the arm model, not held items)

### Requirements
- Minecraft 26.1.2
- NeoForge 26.1.2.78
