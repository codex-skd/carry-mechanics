<h2>v0.0.0-beta.17 - Render fix, entity pickup removed</h2>

<h3>Fix</h3>
<ul>
<li><strong>Carried block rendering</strong>: Mixin moved from <code>renderItem</code> to <code>renderArmWithItem</code> — the correct method that handles empty hands in first-person view. The carried block&#8217;s item is now rendered when the hand is empty.</li>
</ul>

<h3>Changes</h3>
<ul>
<li><strong>Entity pickup disabled</strong>: The mod now only allows carrying blocks (with tile entities). Entities, animals, mobs, and NPCs can no longer be picked up.</li>
</ul>

<h3>Requirements</h3>
<ul>
<li>Minecraft 26.1.2</li>
<li>NeoForge 26.1.2.78</li>
</ul>
