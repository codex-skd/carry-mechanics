<h2>v0.0.0-beta.2 - Fix client crash on world load</h2>

<p>Bug-fix beta. <strong>beta.1 crashes the client</strong> while the loading screen reloads resources; every user of beta.1 should update.</p>

<h3>Fix</h3>
<ul>
<li><strong>Client crash on world load</strong> (<code>InvalidInjectionException</code> → hard crash). <code>AvatarExtractorMixin</code> injected into <code>PlayerRenderer.render(Player, …)</code>, but on 1.21.1 that method takes <code>AbstractClientPlayer</code> (<code>PlayerRenderer extends LivingEntityRenderer&lt;AbstractClientPlayer, …&gt;</code>). No matching target plus <code>defaultRequire: 1</code> aborted mixin application and crashed the client. The <code>@Inject</code> target descriptor and the handler parameter are now <code>net.minecraft.client.player.AbstractClientPlayer</code>.</li>
</ul>

<h3>Technical</h3>
<ul>
<li>Leftover from reverting the 26.2 <code>AvatarRenderer#extractRenderState</code> render-state code to the 1.21.1 immediate renderer; the descriptor was never compile-validated (no mixin annotation-processor refmap on this build).</li>
<li>No gameplay change. Server-side behaviour is identical to beta.1.</li>
</ul>
