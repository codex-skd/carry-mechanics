<h2>v0.0.0-beta.27 &#8212; Mixin Signature Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Crash on startup: <code>InvalidInjectionException</code> in <code>LivingEntityRendererMixin</code></strong>: The <code>@Inject</code> descriptor for <code>onSubmit</code> was using incorrect parameter types (<code>EntityRenderState</code> and <code>Object</code> instead of <code>LivingEntityRenderState</code> and <code>CameraRenderState</code>). This matched the compiled class but not what Mixin expected for MC 26.1.2. The source has been corrected; a fresh recompilation resolves the mismatch.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>LivingEntityRendererMixin.onSubmit()</code>: method descriptor updated to use <code>LivingEntityRenderState</code> and <code>CameraRenderState</code> as required by the target <code>submit()</code> method signature in NeoForge 26.1.2.78.</li>
</ul>
