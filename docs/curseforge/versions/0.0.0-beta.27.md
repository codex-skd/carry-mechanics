<h2>v0.0.0-beta.27 — Code Cleanup &amp; Mixin Fixes</h2>

<h3>Fix</h3>
<ul>
<li><strong>Crash at bootstrap</strong>: Removed duplicate inner <code>AvatarExtractorMixin</code> class inside <code>PlayerRenderStateMixin</code> that had an incorrect <code>@Mixin</code> target (<code>AvatarRenderer</code> inside <code>AvatarRenderState</code> mixin). The standalone <code>AvatarExtractorMixin</code> now handles extraction correctly.</li>
<li><strong>Production readiness</strong>: Removed all <code>[DEBUG]</code> logging from <code>AvatarExtractorMixin</code>, <code>AvatarRendererMixin</code>, and <code>CarryingItemRenderLayer</code>.</li>
<li><strong>CarryingItemRenderLayer</strong>: Replaced debug text overlay with actual block rendering logic, matching the same approach used in <code>LivingEntityRendererMixin</code>.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>PlayerRenderStateMixin</code>: Removed nested <code>@Mixin(AvatarRenderer.class)</code> inner class — Mixin does not support nested mixins on different targets.</li>
<li><code>AvatarExtractorMixin</code>: Cleaned up debug logging, now production-ready.</li>
<li><code>CarryingItemRenderLayer</code>: Now renders carried blocks via <code>BlockModelRenderState</code> instead of a text placeholder.</li>
</ul>
