<h2>v0.0.0-beta.29 — Fix Crouching Render with Dynamic Pose-Aware Positioning</h2>

<h3>Fix</h3>
<ul>
<li><strong>Crouching render not visible</strong>: The carried block now uses <code>state.boundingBoxHeight</code> instead of a fixed <code>translate(0.0, 1.0, 0.0)</code>. This dynamically adjusts the block position for standing (1.8), crouching (1.5), swimming (0.6), and any other pose.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>LivingEntityRendererMixin</code>: Replaced hardcoded Y offset with <code>state.boundingBoxHeight</code> from <code>LivingEntityRenderState</code>.</li>
</ul>
