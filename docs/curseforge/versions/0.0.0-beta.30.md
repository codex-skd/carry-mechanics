<h2>v0.0.0-beta.30 — Fix Client Sync: Carried Objects Now Render</h2>

<h3>Fix</h3>
<ul>
<li><strong>Carried block/entity not visible</strong>: The <code>AttachmentType</code> for carry data was registered without <code>.sync()</code>, meaning the carry data was never synchronized from the server to the client. The client-side <code>CarryDataManager.getCarryData()</code> always returned an empty <code>CarryData</code> with <code>type=INVALID</code>, causing <code>isCarrying()</code> to return <code>false</code> and nothing to render.</li>
<li>Added <code>.serialize(CarryData.CODEC)</code> for NBT persistence and <code>.sync(CarryData.STREAM_CODEC)</code> for client synchronization.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>CarryMechanics.java</code>: <code>CARRY_DATA</code> attachment type now includes serialization and sync handlers.</li>
<li>All previous render fixes (entity caching, boundingBoxHeight, dynamic pose positioning) were correct — the missing client sync was the root cause preventing them from working.</li>
</ul>
