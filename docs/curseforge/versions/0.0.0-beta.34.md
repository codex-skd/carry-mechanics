<h2>v0.0.0-beta.34 — Coordinate System Diagnosis</h2>

<h3>Diagnóstico</h3>
<p>Basado en pruebas anteriores: <code>Y=1.0</code> mostraba el bloque al pie, <code>Y=2.5</code> lo mostraba más abajo aún. Esto indica que el eje Y está invertido en el contexto del RenderLayer, donde Y positivo = abajo.</p>

<h3>Fix</h3>
<ul>
<li>Se usa <code>-(renderState.boundingBoxHeight + 0.5)</code> como desplazamiento Y, lo que coloca el bloque aproximadamente 0.5 bloques por encima de la cabeza del jugador.</li>
<li>Ligero offset lateral <code>(0.3, -0.3)</code> para centrar sobre los hombros.</li>
<li>Sin scale — el bloque se renderiza a tamaño completo para facilitar la evaluación de la posición.</li>
<li>Todos los logs de debug eliminados.</li>
</ul>

<h3>Prueba</h3>
<p>Probar en tercera persona con un barril o cualquier bloque completo. Reportar si aparece sobre la cabeza, a los pies, o en otra posición.</p>
