<h2>v0.0.0-beta.34 — Coordinate System Diagnosis</h2>

<h3>Diagnosis</h3>
<p>Previous tests: <code>Y=1.0</code> placed the block at foot level, <code>Y=2.5</code> placed it lower (1-2 blocks below ground). This suggests the Y-axis is inverted in the RenderLayer context (positive Y = downward).</p>

<h3>Fix</h3>
<ul>
<li>Using <code>-(renderState.boundingBoxHeight + 0.5)</code> as Y offset to place the block approximately 0.5 blocks above the player's head.</li>
<li>Slight lateral offset <code>(0.3, -0.3)</code> to center over the shoulders.</li>
<li>No scaling — block renders at full size for easier position evaluation.</li>
<li>All debug logging removed.</li>
</ul>

<h3>Testing</h3>
<p>Test in third-person view with any full block (e.g. a barrel). Report whether the block appears above the head, at the feet, or elsewhere.</p>
