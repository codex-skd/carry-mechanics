<h2>v0.0.0-beta.36 - Fix block orientation and head position</h2>

<h3>Fix</h3>
<ul>
<li><strong>Block orientation</strong>: Block was rendered upside down. Added Y-axis 180-degree rotation to correct the face alignment.</li>
<li><strong>Head position</strong>: Block was floating above the head with a gap. Adjusted Y-translation so the block sits directly on top of the player's head.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>CarryingItemRenderLayer.submit()</code> — centered X/Z translation (0.0), reduced scale to 0.5, added <code>Axis.YP.rotationDegrees(180)</code> for correct orientation.</li>
</ul>
