<h2>v0.0.0-beta.38 — Build fix for CurseForge verification</h2>

<h3>Fix</h3>
<ul>
<li><strong>Build:</strong> Excluded <code>templates/</code> from the final JAR to prevent invalid metadata (<code>neoforge.mods.toml</code> with unexpanded placeholders) from being included. CurseForge was rejecting previous uploads due to this verification failure.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>build.gradle</code> — added <code>exclude("templates/")</code> in <code>sourceSets.main.resources</code> to avoid leaking template files into the production JAR.</li>
</ul>
