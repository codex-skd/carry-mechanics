<h2>v0.0.0-beta.39 — Fix block rendering position and orientation</h2>

<h3>Fix</h3>
<ul>
<li><strong>Head position:</strong> Block now sits directly on top of the player's head. Removed negative Y offset that was causing a ~1 block gap above the character.</li>
<li><strong>Orientation:</strong> Removed Y-axis 180-degree rotation. Block now faces the same direction as the player instead of being inverted.</li>
<li><strong>Other players:</strong> Added 0.5 scale to the other-player rendering path (<code>LivingEntityRendererMixin</code>) for visual consistency with the avatar's own view.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>CarryingItemRenderLayer.submit()</code> — changed Y translation to <code>renderState.boundingBoxHeight</code> (positive), removed <code>Axis.YP.rotationDegrees(180)</code>.</li>
<li><code>LivingEntityRendererMixin.submit()</code> — added <code>poseStack.scale(0.5f)</code> to match the avatar layer.</li>
</ul>
