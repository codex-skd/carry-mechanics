<h2>v0.0.0-beta.40 — Fix block position on head &amp; crouch visual</h2>

<h3>Fix</h3>
<ul>
<li><strong>Block position:</strong> Fixed Y translation formula. The avatar render layer uses an inverted Y axis, so the block now correctly uses <code>-(boundingBoxHeight + 0.2)</code> to sit on top of the player's head instead of at leg level.</li>
<li><strong>Orientation:</strong> Removed Y-axis 180-degree rotation that was causing the block to face the wrong direction.</li>
<li><strong>Other players:</strong> Added 0.5 scale to <code>LivingEntityRendererMixin</code> for visual consistency with the avatar's own view.</li>
</ul>

<h3>Feat</h3>
<ul>
<li><strong>Crouch visual:</strong> Player now visually appears crouching while carrying a block. This is purely visual — the actual pose, hitbox and camera height are unchanged.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>PlayerMixin.forceCrouchWhenCarrying()</code> — overrides <code>Player.isCrouching()</code> to return true when carrying, which makes the render state extraction use the crouching pose for model rendering.</li>
</ul>
