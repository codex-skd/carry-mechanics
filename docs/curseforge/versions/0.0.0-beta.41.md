<h2>v0.0.0-beta.41 — Fix crash: crouch via render state pose field</h2>

<h3>Fix</h3>
<ul>
<li><strong>Crash fix:</strong> Replaced broken <code>Player.isCrouching()</code> mixin injection with direct render state <code>pose</code> field override. The <code>isCrouching()</code> method was not found on <code>Player</code> in this Minecraft version, causing a mixin injection failure on startup.</li>
<li><strong>Crouch visual:</strong> Now set via <code>state.pose = Pose.CROUCHING</code> in both <code>AvatarExtractorMixin</code> (local player) and <code>LivingEntityRendererMixin</code> (other players) render state extraction.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>AvatarExtractorMixin.onExtractRenderState()</code> — added <code>state.pose = Pose.CROUCHING</code> when carrying.</li>
<li><code>LivingEntityRendererMixin.onExtractRenderStateTail()</code> — new TAIL injection that sets <code>state.pose = Pose.CROUCHING</code> for other players when carrying.</li>
<li><code>PlayerMixin</code> — removed broken <code>isCrouching</code> injection (method doesn't exist on Player in this MC version).</li>
</ul>
