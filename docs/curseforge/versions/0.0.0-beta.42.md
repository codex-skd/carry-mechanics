<h2>v0.0.0-beta.42 — First-person rendering, hand-anchored block, jump lock, real crouch pose</h2>

<h3>Fix</h3>
<ul>
<li><strong>First-person rendering:</strong> the carried block was not rendered at all when looking through the local player's own view. Added a new render hook on <code>ItemInHandRenderer</code> so the carried block is now visible in first person.</li>
<li><strong>Floating block / shoulder pop in third person:</strong> the carried block was drawn twice by two separate, uncoordinated render paths (one duplicating the other), each using a fixed offset from the player's bounding box height instead of the model's hand bone. This caused the block to float above the head and jump onto the shoulder when the camera angle changed. Removed the duplicate draw path and anchored the remaining one to the player model's hand.</li>
<li><strong>Jumping while carrying:</strong> players could still jump while carrying a block, mob, or another player. Jumping is now fully cancelled while carrying, both on the client input and on the server.</li>
<li><strong>Crouch pose not visible:</strong> the crouched pose while carrying was only set on the render state's <code>pose</code> field, which the player model's animation does not read. The actual <code>isCrouching</code> flag used by the humanoid animator is now also set, so the crouched pose is visible in third person for both the carrier and other players observing them.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>ItemInHandRendererMixin</code> (new) — injects into <code>ItemInHandRenderer.renderHandsWithItems</code> to draw the carried block in first person.</li>
<li><code>CarriedBlockRenderer</code> (new) — shared helper that resolves and submits the carried block's model, used by both the first-person and third-person render paths.</li>
<li><code>CarryingItemRenderLayer</code> — now anchors the block to the hand via <code>PlayerModel.translateToHand(...)</code> instead of a fixed offset from <code>boundingBoxHeight</code>.</li>
<li><code>LivingEntityRendererMixin</code> — removed the duplicate <code>submit()</code> block-draw injection; now only forces the crouch pose (<code>pose</code> and <code>isCrouching</code>) on <code>extractRenderState</code>.</li>
<li><code>AvatarExtractorMixin</code> — now also sets <code>isCrouching</code> alongside <code>pose</code> for the local/other-player avatar render state.</li>
<li><code>LivingEntityMixin</code> (new) — cancels <code>setJumping(true)</code> and <code>jumpFromGround()</code> while the player is carrying something.</li>
</ul>
