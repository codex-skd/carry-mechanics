<h2>v0.0.0-beta.46 — Carried entities are now visible, hostile mobs blocked by Enemy interface, player pickup removed</h2>

<h3>Feat</h3>
<ul>
<li><strong>Carried animals and villagers are now visible</strong> in both first and third person. They render piggyback-style on the player's back/shoulders, with their rear toward the player and their head facing the direction the player is walking. Uses the same entity-render-dispatcher approach as Carry On, adapted for this Minecraft version's render state system.</li>
<li><strong>Hostile mob blocking via <code>Enemy</code> interface:</strong> on top of the existing <code>MobCategory.MONSTER</code> check, the mod now also checks <code>entity instanceof Enemy</code> (the vanilla marker interface implemented by zombies, skeletons, creepers, etc.) for a more robust criterion that doesn't rely solely on datapack tags or category enums.</li>
</ul>

<h3>Removed</h3>
<ul>
<li><strong>Player pickup has been removed entirely:</strong> the <code>pickupPlayers</code> config option, the associated code branches in <code>PickupHandler</code> and <code>PlacementHandler</code>, and the README entries are gone. The networking packets <code>ClientboundStartRidingOtherPlayerPacket</code> and <code>ClientboundStartRidingPacket</code> remain registered but are never sent.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>CarriedObjectRender.drawEntity()</code> (new) — renders a carried entity via <code>EntityRenderDispatcher.extractEntity()</code>/<code>submit()</code>, with shadow disabled and camera state auto-created.</li>
<li><code>CarryRenderHelper.setupEntityTransformations()</code> and <code>applyEntityTransformations()</code> (new) — matrix transforms for entity rendering, adapted from Carry On: 180° X pitch, positioning behind player's head/back, adaptive scaling by entity size, and sneak/swim support.</li>
<li><code>PickupHandler.tryPickupEntity()</code> — blocks player pickup with early <code>instanceof Player</code> return; blocks hostile mobs with combined <code>Enemy</code> + <code>MobCategory.MONSTER</code> check.</li>
<li><code>CarryConfig</code> / <code>ConfigData</code> / <code>ConfigAccess</code> — removed <code>pickupPlayers</code> config option.</li>
<li><code>HumanoidModelMixin</code> — arm pose now applies to both BLOCK and ENTITY carried types (wider Y-spread for entities, matching the piggyback posture).</li>
<li><code>ClientEvents.onRenderHand()</code> — first-person hand cancellation now covers both BLOCK and ENTITY, not just blocks.</li>
</ul>
