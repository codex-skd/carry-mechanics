## v0.0.0-beta.8

**Fix:** Object pickup was unreliable due to network latency between the key packet and the right-click event.

### Changes
- Removed custom key packet system (`ServerboundCarryKeyPressedPacket`)
- Now uses vanilla crouch state (`player.isCrouching()`) to detect Shift
- Pickup works instantly and reliably
- Right-click events no longer cancel if no action was performed

### How to use
Sneak (**Shift**) + right-click to pick up. Right-click alone to place.

### Requirements
- Minecraft 26.1.2
- NeoForge 26.1.2.78

### Known issues
- Carried object has no visual rendering (invisible)
