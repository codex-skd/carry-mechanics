<h2>v1.0.0 — First stable Fabric release</h2>

<p>Carry Mechanics for Fabric reaches its first stable release for Minecraft 26.2 (Fabric Loader 0.19.3 / Fabric API 0.156.0).</p>

<h3>Notes</h3>
<ul>
<li>No functional changes since <code>0.0.0-beta.1</code> — this release only marks the Fabric port as stable (<code>mod_version</code> bumped from <code>0.0.0-beta.1</code> to <code>1.0.0</code>).</li>
<li>Includes the rendering fixes carried over from the NeoForge build (safe pose-stack rendering and carried-entity ID assignment), so carried mobs render correctly in first and third person.</li>
<li>Carrying, stacking and placing blocks and entities, datapack tags, scripting, commands and config (<code>config/carry_mechanics.json</code>) work as in the beta.</li>
</ul>
