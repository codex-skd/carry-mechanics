<h2>v1.0.0 — First stable release</h2>

<p>Carry Mechanics leaves beta and reaches its first stable release for Minecraft 26.1.2. After 47 beta builds, the core feature set (carrying blocks, entities and tile entities, entity stacking, whitelist/blacklist via datapack tags, scripting, commands and full multiplayer sync) is considered stable.</p>

<h3>Notes</h3>
<ul>
<li>No functional changes since <code>0.0.0-beta.47</code> — this release only marks the mod as stable (<code>mod_version</code> bumped from <code>0.0.0-beta.47</code> to <code>1.0.0</code>).</li>
<li>See the changelog for the full history of fixes and features across all beta builds.</li>
</ul>
