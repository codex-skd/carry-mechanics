<h2>v1.0.0 - First stable release (Minecraft 1.21.1)</h2>

<p>First stable release of Carry Mechanics for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>
(Java 21). It consolidates the <code>0.0.0-beta.1</code> &rarr; <code>0.0.0-beta.3</code> line with
no further code changes. This build has been running server-side in a full modded-server pack.</p>

<h3>What the 1.21.1 line brought</h3>
<ul>
<li><strong>Port from the 26.2 fork tree</strong> (<code>com.skd.carrymechanics</code> identity), all
26.2-only Minecraft/NeoForge API reverted to 1.21.1 using upstream Carry On 1.21.1 (v2.2.6, Tschipp /
PurpliciousCow, LGPL-3.0) as the API reference. The fork's own gameplay dynamics &mdash;
crouch-to-pick-up, grab rules, carry conditions, entity stacking, scripting, model overrides,
movement penalties and inventory locking &mdash; are preserved unchanged.</li>
<li><strong>Client crash fix</strong>: <code>AvatarExtractorMixin</code> now targets
<code>PlayerRenderer.render(AbstractClientPlayer, &hellip;)</code>, the correct 1.21.1 signature.</li>
<li><strong>Spanish (<code>es_es</code>) locale</strong> bundled: all 32 keys (creative-tab name,
&laquo;Cargar&raquo; keybind, every config-screen label).</li>
</ul>

<h3>Notes</h3>
<blockquote>No gameplay change relative to <code>0.0.0-beta.3</code>. Verified:
<code>./gradlew clean build</code> is green. Shares this CurseForge project with the 26.2 line &mdash;
pick the file that matches your Minecraft version.</blockquote>
