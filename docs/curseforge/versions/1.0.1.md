<h2>v1.0.1 — Fix: severe lag / freeze when carrying entities</h2>

<p>Fixes the game slowing down until it freezes when carrying a mob, animal or villager (and any other complex mod entity).</p>

<h3>Fix</h3>
<ul>
<li><strong>Performance</strong>: <code>CarryData.getEntity()</code> re-deserialized the full entity NBT on every call. On the client this ran twice per frame (render) and on the server once per tick (slowness calculation), so complex entities such as villagers with a brain, inventory and trades saturated the garbage collector and froze the game. The deserialized entity is now cached and reused until the carried NBT changes or the level changes.</li>
</ul>

<h3>Notes</h3>
<ul>
<li>No functional changes — carrying, stacking and placing work exactly as in <code>1.0.0</code>.</li>
</ul>
