<h2>v1.0.3 — Fix: carried entities are now visible</h2>

<p>Fixes carried mobs, animals and villagers being completely invisible in first and third person (and the related per-frame lag caused by a render error).</p>

<h3>Fix</h3>
<ul>
<li><strong>Entity ID not assigned</strong>: a carried entity is deserialized as a detached copy that never enters the level, so it had no entity id assigned. Client-side render state extraction (<code>ItemModelResolver.updateForLiving</code>) calls <code>entity.getId()</code>, which threw <code>IllegalStateException: Tried to access entity ID before ID assignment</code>. The exception was silently swallowed every frame, so the mob never appeared in your hands and the game stuttered. The render copy now gets a unique non-zero id and the carried entity renders correctly in both views.</li>
</ul>

<h3>Notes</h3>
<ul>
<li>Block carrying was unaffected and still works.</li>
<li>Carrying, stacking and placing work as in <code>1.0.2</code>.</li>
</ul>
