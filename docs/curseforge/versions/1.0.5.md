<h2>v1.0.5 — Fix: carried blocks keep the wrong orientation on placement</h2>

<p>Fixes carried blocks with an orientation property always being placed facing the way they were picked up, instead of facing where the player is looking.</p>

<h3>Fix</h3>
<ul>
<li><strong>Orientation not recalculated on placement</strong>: any carried block with a <code>FACING</code>/<code>HORIZONTAL_FACING</code> or <code>AXIS</code> property (barrels, furnaces, dispensers, observers, logs, etc.) ignored the direction the player was looking at when placing it back down. The placement logic already computed the correct orientation via <code>getStateForPlacement</code>, but an unconditional post-processing step overwrote it with the orientation saved at pickup time. That override has been removed, so orientation is now recalculated exactly like a normal vanilla placement.</li>
</ul>

<h3>Notes</h3>
<ul>
<li>Affects any block with a <code>Direction</code>/<code>Direction.Axis</code> blockstate property, not just barrels.</li>
<li>Entity carrying/stacking/placing is unaffected.</li>
</ul>
