<h2>v1.0.6 — Fix: hostile mob pickup exceptions (Warlockery goblins)</h2>

<p>Adds a way to exempt specific hostile mobs from the hostile-mob pickup filter, and uses it by default for Warlockery's goblins.</p>

<h3>Fix</h3>
<ul>
<li><strong>Warlockery goblins/hobgoblins couldn't be carried</strong>: they are registered with <code>MobCategory.MONSTER</code> and implement <code>Enemy</code>, so the hostile-mob filter blocked picking them up whenever <code>pickup_hostile_mobs</code> was disabled, just like any other hostile mob. A new data tag, <code>carry_mechanics:hostile_pickup_whitelist</code> (entity_type), now bypasses that filter for any entity type listed in it. <code>warlockery:goblin</code> and <code>warlockery:hobgoblin</code> are included by default (as non-required entries, so nothing breaks if Warlockery isn't installed).</li>
</ul>

<h3>Notes</h3>
<ul>
<li>Every other hostile mob is still blocked unless <code>pickup_hostile_mobs</code> is enabled, or you add its entity type to <code>hostile_pickup_whitelist</code> yourself via a datapack.</li>
<li>This is independent of the existing <code>entity_whitelist</code>/<code>entity_blacklist</code> tags.</li>
</ul>
