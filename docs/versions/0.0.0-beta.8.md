## v0.0.0-beta.8

**Fix:** Pickup de objetos no funcionaba por latencia entre el paquete de tecla y el click derecho.

### Cambios
- 🔧 Eliminado el sistema de paquete custom de tecla (`ServerboundCarryKeyPressedPacket`)
- 🔧 Ahora se usa el estado de agachado vanilla (`player.isCrouching()`) para detectar Shift
- ✅ El pickup funciona de forma inmediata y fiable
- ✅ Ya no se cancela el evento de click derecho si no se realiza ninguna acción

### Cómo usar
Agacharse (**Shift**) + click derecho para recoger. Click derecho solo para colocar.

### Requisitos
- Minecraft 26.1.2
- NeoForge 26.1.2.78
